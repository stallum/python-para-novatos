# Python para Leigos
> Este repositório é um guia simples para o aprendizado da linguagem Python, lógica de programação e boas práticas de desenvolvimento.

## 🗺️ Trilha de Estudos Recomendada
Siga a ordem dos módulos estruturados para um aprendizado progressivo:

**01_logica_e_algoritmos: Fundamentos do pensamento computacional.**

**02_fundamentos_python: Sintaxe base, tipos, controle de fluxo e funções.**

**03_estruturas_de_dados: Manipulação eficiente usando listas, tuplas, conjuntos e dicionários.**

**04_boas_praticas_e_desenvolvimento: Padrões da comunidade (PEP 8), tratamento de erros e organização de código.**

**05_projetos_aplicados: Prática com desafios reais para consolidação e montagem de portfólio.**

## 📚 Estrutura de Cada Módulo
Dentro de cada pasta acima, você sempre encontrará as seguintes seções:

`teoria/`: Conceitos explicados de forma teórica e direta (sem enrolação).

`exemplos/`: Scripts ilustrativos para execução prática.

`exercicios/`: Desafios focados na fixação do conteúdo.

`resolucoes/`: Gabaritos oficiais com a abordagem mais "Pythônica".
