Algoritmo é uma **sequência de instruções finita** sem ambiguidade que servem para resolver um problema ou realizar uma tarefa

## O que é um algoritmo?
Na computação e matemática, um algoritmo é utilizado para definir instruções de como realizar um problema seguindo o modelo IPO (Imput, Process e Output). Funciona como uma receita de bolo, recebe-se ingredientes *(Input)*, são utilizados seguindo passos específicos para serem devidamente processados *(Process)* e no final tem-se um bolo *(Output)*

As principais características de um bom algoritmo são: 
- **Finitude.** Precisa terminar após um número contável de passos.
- **Precisão.** Cada instrução deve ser simples e bem definida.
- **Efetividade.** Os passos devem ser executáveis e capaz de solucionar o probblema proposto.

## Tipos de Algoritmo
Algoritmos para a computação podem ser definidos por sua estrutura lógica básica ou por sua função de aplicação na computação, como em estrutura de dados ou em sistemas de inteligência artifical. 

- **Algoritmos por Estrutura Lógica.** 
  - **Sequencial.** Executa as instruções de maneira linear, do início ao fim, sem desvios.
  - **Condicional.** Avalia uma condição para seguir os caminhos diferentes com base em estruturas lógicas básicas como "se... então...".
  - **Repetição.** Executa um conjunto de instruções diversas vezes até que uma condição específica seja satisfeita.

- **Algoritmos por Função na Computação.**
  - **De busca.** Localizam um item específico dentro de um conjunto de dados ou banco de dados (ex: busca linear ou busca binária).
  - **De ordenação.** Organizam elementos de uma lista em uma ordem lógica, como numérica ou alfabética (ex: Quicksort, bubble sort).
  - **Recursivos.** Resolvem um problema chamando a si mesmos repetidamente até atingirem uma condição de parada.
  - **Ganaciosos. (Greedy)** Tomam a melhor decisão local em cada etapa com o objetivo de alcançar a solução global ideal.

- **Algoritmos em Inteligências Artificiais.**
  - **De aprendizado de máquina (Machine Learning).** Permitem que os sistemas reconheçam padrões e aprendam com grandes volumes de dados.
  -  **De classificação ou regressão.** Categorizam dados em classes distintas ou preveem valores numéricos contínuos (ex: árvores de decisão e regressão logística).
