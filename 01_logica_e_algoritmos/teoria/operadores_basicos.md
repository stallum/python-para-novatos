Os operadores são responsáveis por realizar as operações em um programa. Soma, Subtração, Divisão, Multiplicação e outros operadores são utilizado no python. 

## Simples
Soma, Subtração, Multiplicação e Divisão são representados respectivamente por: "`+`", "`-`", "`*`" e "`/`". Além dessas quatro existem outras operações em pythom com operandos diferentes.

## Outros Matemáticos
- **Resto de Divisão.** O Simbolo utilizado para marcar o resto de divisão é "`%`". Ela é utilizada da seguinte forma `x % y` o o retorno gerado é o resto da divisão de `x` e `y`.
- **Divisão Inteira.** O Simbolo utilizado para pegar apenas o valor inteiro de uma divisão (arrendodado para cima) é `//`. Ela é utilizada no seguinte padrão `x // y` o retorno gerado é o valor inteiro da divisão arrendodadno para cima.
- **Exponenciação.** O Simbolo utilizado para a exponenciação na linguagem de programação python é `**`. Utilizada da seguinte forma `x ** y` e o output gerado é o valor de `x` elevado ao valor de `y`.

## Lógicos
- **Operador lógico E (AND).** Para utilizar o operador lógico "E" na linguagem de programação python, utilizasse o `and`.
- **Operador lógico OU (or).** Para utilizar o operador lógico "OU" na linguagem de programação python, utilizasse o `or`.
- **Operador lógico NÃO (not).** Para utilizar o operador lógico "NÃO", operador de negação, utiliza-se uma `!`.
