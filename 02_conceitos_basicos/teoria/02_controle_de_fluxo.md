Controle de fluxo é a forma de fazer o código fazer o que você quer que seja feito. Ou seja, se você quer que em determinado ponto do código ele verifique uma informação e daí descida entre uma rota e outra do código ele seguirá a rota descidida a partir do processamento do dado de entrada.

Essa forma de sequência do código é realizada pela função própria do python `if` e seus complementos como o `else` e o `elif`.

## if
A função `if` é a principal função para o controle de fluxo, nela você joga o poder de decisão de executar trecho dos códigos a partir de uma **condição** estabelecida nos parâmetros da função.

```python
# Exemplo de ccódigo com if.
i = 2
print(1)
if i == 2: 
    print(2)

```

dessa forma, caso o valor de i seja alterado para qualquer outro valor que não seja o inteiro 2, o código apenas exibe o valor `1`.

## else
